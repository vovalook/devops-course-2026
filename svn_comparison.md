# Сравнение Git и SVN

## 1. Почему в Git ветвление дешёвое, а в SVN дорогое?

В Git ветки создаются быстро и являются частью распределённой системы контроля версий. В SVN работа с ветками исторически связана с копированием директорий на центральном сервере.

## 2. Можно ли в SVN сделать коммит без интернета?

Обычно для коммита требуется доступ к центральному SVN-серверу. В Git коммиты можно делать локально без подключения к интернету.

## 3. Где SVN всё ещё может использоваться?

SVN может встречаться в старых проектах и организациях, где уже существует большая инфраструктура на основе SVN и переход на другую систему нецелесообразен.
